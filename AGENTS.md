# AGENTS.md

This repository contains OpenCode skills.

## Structure

- `*.skill` files - Skill metadata and configuration
- `*/SKILL.md` - Skill documentation and instructions

## Skills

- `first-principles-teacher` - A teaching skill for explaining math/CS concepts using first-principles pedagogy
- `content-maker` - Generate exhaustive, phase-wise learning roadmaps and content plans for any topic, subject, technology, or skill
- `image-to-html` - Convert images (screenshots, mockups, designs) into pixel-perfect, functional HTML/CSS webpages

## Notes

- Skills are loaded via the OpenCode `skill` tool
- Trigger phrases are defined in the skill metadata
